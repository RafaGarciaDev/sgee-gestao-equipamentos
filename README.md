# 🎯 SGEE — Sistema de Gestão de Equipamentos Empresariais

API REST em **Java 21 + Spring Boot** para controlar equipamentos da empresa, tipos de equipamento, funcionários, **empréstimos** e o **histórico de movimentações**. Projeto desenvolvido em equipe no **Hackathon AGI**.

![Java](https://img.shields.io/badge/Java_21-ED8B00?style=flat-square&logo=openjdk&logoColor=white) ![Spring Boot](https://img.shields.io/badge/Spring_Boot_3.4-6DB33F?style=flat-square&logo=springboot&logoColor=white) ![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![MongoDB](https://img.shields.io/badge/MongoDB-47A248?style=flat-square&logo=mongodb&logoColor=white) ![Swagger](https://img.shields.io/badge/Swagger-85EA2D?style=flat-square&logo=swagger&logoColor=black)

## ✨ Funcionalidades
- CRUD de equipamentos, tipos de equipamento e funcionários
- Registro de empréstimos
- Histórico de movimentações com filtros
- Documentação interativa com Swagger (SpringDoc OpenAPI)

## 🛠️ Tecnologias
Java 21 · Spring Boot 3.4 · Spring Data JPA (MySQL) · Spring Data MongoDB · Lombok · Gradle · SpringDoc OpenAPI

## ▶️ Como rodar
```bash
cd SGEE/SGEE-main
./gradlew bootRun
```
